# astrbot_plugin_sponsor_pass

陌生人准入、爱发电订单核验、微信支付/支付宝商户订单查询和会员权益发放插件，适用于 AstrBot + OneBot v11（`aiocqhttp`）。

爱发电是默认主流渠道；微信支付和支付宝仅支持官方商户 API。个人微信收款码、个人支付宝收款码没有可供插件可靠调用的官方订单查询接口，因此不会被当作自动验单渠道。

## 功能

- 非白名单好友先免费对话 N 轮，固定窗口计数，不会通过持续发言无限延长第一轮；
- 支持好友私聊和可选临时会话；群聊、好友申请、通知事件不会被本插件抢占；
- 管理员同意后清理拦截状态，并主动通知申请人；
- 爱发电赞助、售卖商品、数字内容、实体商品和捆绑包订单核验；
- 微信支付商户 API v3 的订单查询适配；
- 支付宝开放平台当面付交易查询适配；
- 适配器还提供官方 Native/预创建下单二维码接口，是否启用由商户配置决定；
- 自动会员放行仍必须以官方订单查询或已验证回调为准；
- 支持金额阶梯、方案 ID/商品 ID 白名单和商品按份叠加有效期；
- 支持直接发送爱发电长订单号，或带渠道前缀发送微信/支付宝商户订单号；
- 每笔订单按支付渠道命名空间只能核销一次，并通过持久化台账和异步锁防止重复兑换；
- 对忘填 QQ、写错 QQ、未支付、金额不足、已核销和接口故障分别处理；
- 待审批队列、黑名单、限时会员、通知重试、自检和按渠道收入统计；
- 状态持久化、损坏恢复、`Decimal` 金额比较和官方 API 地址校验。

## 支付渠道说明

### 爱发电

默认渠道。配置 `afdian_url`、`afdian_user_id` 和 `afdian_token` 后，可以通过赞助留言 QQ、爱发电订单号和管理员人工绑定核验。

### 微信支付商户 API

仅支持微信支付商户 API v3。需要配置：

- `wechat_appid`：与商户号绑定的 AppID；
- `wechat_mchid`：商户号；
- `wechat_serial_no`：商户 API 证书序列号；
- `wechat_private_key`：商户 API 私钥 PEM；
- `wechat_api_v3_key`：用于支付通知资源解密；
- `wechat_notify_url`：可选通知地址。

插件支持按商户订单号查询和 Native 支付二维码生成。生产环境建议使用公网可访问的 HTTPS 回调服务，在服务端完成平台签名验证、资源解密、金额/商户/订单校验和幂等落库。没有回调服务时只能使用官方查询接口轮询，并应控制频率。

### 支付宝开放平台

仅支持支付宝开放平台商户模式。需要配置：

- `alipay_app_id`：应用 AppID；
- `alipay_private_key`：应用 RSA2 私钥；
- `alipay_public_key`：支付宝公钥；
- `alipay_notify_url`：可选异步通知地址。

插件支持 `alipay.trade.query` 查询和 `alipay.trade.precreate` 预创建二维码。生产环境建议使用公网可访问的 HTTPS 通知服务，在服务端验签、校验商户和金额并幂等处理。个人支付宝收款码不支持自动验单。

## 安装

在 AstrBot WebUI 插件市场搜索 `astrbot_plugin_sponsor_pass`，或从 GitHub 安装：

```text
https://github.com/Nevino2333/astrbot_plugin_sponsor_pass
```

依赖写在 `requirements.txt` 中。插件声明支持平台为 `aiocqhttp`；其它适配器需要先验证主动私聊能力。

## 配置

### 通用配置

| 配置 | 作用 |
| --- | --- |
| `whitelist` | 始终放行的 QQ 列表 |
| `max_rounds` | 免费对话轮数，默认 6 |
| `round_window` | 固定轮次窗口，默认 180 秒 |
| `min_amount` | 最低实付金额，默认 5 |
| `sponsor_expire_days` | 默认会员有效天数，0 表示永久 |
| `amount_tiers` | 金额阶梯，例如 5 元 7 天、20 元 30 天 |
| `allowed_plan_ids` | 允许自动兑换的爱发电方案 ID，留空不限制 |
| `allowed_product_ids` | 允许自动兑换的爱发电商品 ID，留空不限制 |
| `max_product_units` | 单笔商品最大自动兑换份数 |
| `stack_product_units` | 商品多份购买是否叠加有效期 |

### 渠道开关

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `enable_sponsor` | `true` | 爱发电赞助/订单号核验 |
| `enable_order_code` | `true` | 爱发电订单号兑换 |
| `enable_wechat` | `false` | 微信支付商户 API，个人收款码无效 |
| `enable_alipay` | `false` | 支付宝商户 API，个人收款码无效 |

微信私钥、API v3 Key、支付宝私钥和支付宝公钥只填写在 AstrBot 配置中，不要提交到 GitHub、README、日志或状态文件。未配置完整的渠道不会处理其订单。

## 用户流程

达到免费轮数后，陌生人可以等待管理员同意，或使用已经配置的支付渠道。

公开帮助：

```text
准入帮助
```

已进入拦截状态时也可以发送 `帮助`；未进入拦截状态时，通用 `帮助` 不会被本插件拦截，会交给 AstrBot 或其它插件处理。

爱发电订单号：

```text
订单号: 202510121138244856494931049
```

微信和支付宝订单号必须带渠道前缀：

```text
微信订单号: 商户订单号
支付宝订单号: 商户订单号
```

普通数字、QQ 号、付款截图和用户自述都不会直接获得权限。插件必须调用对应官方 API 精确查询订单。

## 订单防呆和核销

- 忘记填写爱发电留言 QQ：可以发送爱发电订单号自助兑换，或让管理员执行 `/准入 订单 <订单号> <QQ>`；
- 订单状态不明确、金额异常、未支付或接口故障时不会自动放行；
- 同一支付渠道的订单只能绑定一个 QQ 一次；
- 多支付渠道使用独立命名空间，避免不同平台订单号碰撞；
- 商品数量异常、未知商品或超过最大份数时转人工处理；
- 兑换成功后通知申请人和管理员，通知失败不回滚订单核销。

## 商品和会员方案

支持爱发电售卖商品和捆绑包。商品数量从 `sku_detail` 中解析，并受 `max_product_units` 限制。

金额阶梯示例：

```json
[
  {"min_amount": 5, "expire_days": 7},
  {"min_amount": 20, "expire_days": 30},
  {"min_amount": 50, "expire_days": 90},
  {"min_amount": 100, "expire_days": 0}
]
```

`expire_days: 0` 表示永久有效。配置 `allowed_plan_ids` 或 `allowed_product_ids` 后，只有命中允许列表的订单可以自动兑换。

## 状态、统计和隐私

运行状态保存在：

```text
data/plugin_data/astrbot_plugin_sponsor_pass/state.json
```

状态包含轮次、待处理申请、放行凭证、订单核销台账、最小化审计摘要和统计数据。不会保存任何支付私钥、API v3 Key 或爱发电 token。

`/准入 自检` 只显示各渠道配置是否完整，不显示密钥。`/准入 统计` 只统计已完成核验和核销的订单金额。

## 与其它插件兼容

- 未受阻阶段不抢占通用 `帮助`；
- `准入帮助` 是本插件专用入口；
- 好友申请和通知事件放行给人际关系管理插件；
- 使用 whitelistpro 时关闭其好友私聊白名单子开关，避免重复拦截；
- whitelistpro 的群聊白名单和其它独立控制功能可以继续使用。

## 安全边界

- 微信和支付宝只支持商户 API，不支持个人收款码自动验单；
- 不读取个人账单、不抓包、不模拟手机客户端、不使用非公开接口；
- 不自动加好友、不自动接受好友、不高频轮询；
- 不因订单号格式看起来正确就放行；
- 生产回调必须自行部署、验签、解密、校验和幂等落库。
