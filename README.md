# astrbot_plugin_sponsor_pass

陌生人准入、爱发电订单核验和会员权益发放插件，适用于 AstrBot + OneBot v11（`aiocqhttp`）。

本插件将“陌生人先体验、管理员审核或完成已验证赞助后获得准入”的流程自动化。自动放行只接受爱发电 API 返回的真实已支付订单，不接受用户自述、任意数字、昵称匹配或本地猜测。

## 1. 功能

- 非白名单好友先免费对话 N 轮，使用固定窗口计数，不会通过持续发言无限延长第一轮；
- 支持好友私聊和可选临时会话；群聊、好友申请、通知事件不会被本插件抢占；
- 管理员同意后自动清理拦截状态，并通过当前 OneBot 连接通知申请人；
- 爱发电普通赞助、售卖商品、数字内容、实体商品和捆绑包订单核验；
- 支持金额阶梯、方案 ID/商品 ID 白名单和商品按份叠加有效期；
- 支持直接发送爱发电长订单号兑换，解决用户忘记填写 QQ 留言的问题；
- 每笔订单只能核销一次，并通过持久化台账和异步锁防止重复兑换；
- 对忘填 QQ、写错 QQ、未支付、金额不足、已核销和接口故障分别处理；
- 待审批队列、黑名单、限时会员、通知重试、自检和收入统计；
- 状态持久化、损坏恢复、`Decimal` 金额比较和固定 API host 校验。

## 2. 安装

在 AstrBot WebUI 插件市场搜索 `astrbot_plugin_sponsor_pass`，或从 GitHub 安装：

```text
https://github.com/Nevino2333/astrbot_plugin_sponsor_pass
```

依赖写在 `requirements.txt` 中。插件支持平台声明为 `aiocqhttp`；其它适配器需要先验证主动私聊能力。

## 3. 快速配置

在 AstrBot WebUI 的插件配置中填写：

| 配置 | 作用 |
| --- | --- |
| `afdian_url` | 爱发电主页链接 |
| `afdian_user_id` | 爱发电开发者设置中的 user_id |
| `afdian_token` | 爱发电开发者设置中的 token |
| `notify_target` | 管理员 QQ；留空时自动使用 AstrBot `admins_id` |
| `min_amount` | 最低实付金额，默认 5 |
| `max_rounds` | 免费对话轮数，默认 6 |
| `round_window` | 固定轮次窗口，默认 180 秒 |

未完整配置爱发电时，插件只提供管理员同意路径，不会展示无效赞助入口。

## 4. 陌生人流程

达到免费轮数后，陌生人会收到两种准入方式：

1. 等待管理员同意；
2. 完成爱发电赞助或购买，然后发送「我赞助了」「我购买了」，或者直接发送订单号。

陌生人可以在任意阶段发送：

```text
准入帮助
```

已经进入拦截状态时，也可以发送：

```text
帮助
```

未进入拦截状态时，通用 `帮助` 不会被本插件拦截，会交给 AstrBot 或其它帮助插件处理。

## 5. 爱发电订单号兑换

用户可以发送：

```text
订单号: 202510121138244856494931049
```

也支持：

```text
订单码: 202510121138244856494931049
兑换码: 202510121138244856494931049
兑换: 202510121138244856494931049
```

订单号兑换不依赖订单留言 QQ，适合忘记填写留言的情况。插件会调用爱发电 `query-order` API，要求：

- 输入订单号与 API 返回的 `out_trade_no` 完全一致；
- `status == 2`，订单已支付；
- `total_amount` 可解析且达到最低金额；
- 订单商品/方案符合配置；
- 订单未被任何 QQ 核销过。

普通 QQ 号、金额、短数字和随机长数字不会直接放行。订单格式通过后仍必须经爱发电 API 精确确认。

兑换成功后记录：

```text
订单号 -> 当前发送者 QQ
```

同一个订单只能兑换一次，之后不能换绑其他 QQ。

## 6. 订单防呆

### 忘记填写 QQ

如果查到有效订单但留言没有 QQ，插件会向申请人显示订单号并通知管理员。管理员确认后执行：

```text
/准入 订单 <订单号> <QQ号>
```

插件会重新查询订单并检查支付状态、金额、商品规则和核销台账。

### 留言写错 QQ

如果留言写了其它数字但不是当前申请人的 QQ，插件只提示人工处理，不会自动误绑定。

### 订单异常

以下情况不会自动放行：

- 订单不存在；
- 爱发电接口不可用；
- 订单未支付；
- 金额不足；
- 状态或金额字段异常；
- 订单已核销；
- 商品数量非法或超过上限；
- 方案/商品不在允许列表中。

## 7. 商品和会员方案

支持爱发电售卖商品和捆绑包。商品数量从 `sku_detail` 中解析，并受 `max_product_units` 限制。

金额阶梯可配置为：

```json
[
  {"min_amount": 5, "expire_days": 7},
  {"min_amount": 20, "expire_days": 30},
  {"min_amount": 50, "expire_days": 90},
  {"min_amount": 100, "expire_days": 0}
]
```

含义是按实付金额选择最高匹配权益，`expire_days: 0` 表示永久有效。

商品策略：

- `allowed_plan_ids` 留空表示不限制方案；
- `allowed_product_ids` 留空表示不限制商品；
- 任意一个列表配置后，订单必须命中允许的方案或商品；
- `stack_product_units: true` 时按购买份数叠加有效期；
- 数量异常、结构异常或超过上限时转人工处理。

## 8. 管理命令

仅 AstrBot 管理员可用：

```text
/准入 帮助
/准入 待处理
/准入 同意 <QQ> [天数]
/准入 移除 <QQ>
/准入 拉黑 <QQ>
/准入 解黑 <QQ>
/准入 订单 <订单号> <QQ>
/准入 通知重试 <QQ>
/准入 自检
/准入 状态 <QQ>
/准入 重置 <QQ>
/准入 统计
/准入 列表
```

`/准入 统计` 会显示门槛触发、赞助直通、手动放行、已核销订单、累计实付金额、有效凭证和待处理数量。

`/准入 自检` 会显示版本、功能开关、管理员、爱发电凭据完整性、订单号兑换开关、状态文件和核销数量，不会显示 token。

## 9. 状态和隐私

运行状态保存在：

```text
data/plugin_data/astrbot_plugin_sponsor_pass/state.json
```

状态包含轮次、待处理申请、放行凭证、订单核销台账、最小化审计摘要和统计数据。爱发电 token 不写入插件状态，也不会写入日志。

建议使用服务器文件权限保护 `data/plugin_data`。争议订单和异常订单必须由管理员人工确认。

## 10. 与其它插件兼容

- 通用 `帮助` 不会在未受阻阶段被本插件抢占；
- `准入帮助` 是本插件专用入口；
- 好友申请和通知事件会放行给人际关系等插件；
- 如果启用了 whitelistpro，请关闭它的“好友私聊白名单”子开关，避免两个准入插件同时拦截；
- whitelistpro 的群聊白名单、临时会话控制和其它独立功能可以继续使用。

## 11. 安全边界

- 只允许访问爱发电官方 HTTPS API host；
- 拒绝 localhost、环回、私有和保留地址；
- 不自动接受好友、不自动加好友、不高频轮询；
- 不凭昵称或用户自述匹配订单；
- 不绕过爱发电 API；
- 不因“看起来像订单号”而放行。
