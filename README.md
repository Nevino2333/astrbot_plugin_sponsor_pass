# astrbot_plugin_sponsor_pass · 陌生人准入·赞助直通

非白名单好友私聊先自由聊 N 轮（默认 6 轮，连发消息在同一合并窗口内算同一轮），
超过轮数后机器人会给出两条路：

1. **等待管理员同意**：管理员用 `/准入 同意 <QQ号> [天数]` 放行（可限时），
   放行后自动私聊通知申请人"通过啦"；
2. **爱发电赞助/购买直通**：对方去你的爱发电主页赞助或购买商品（留言备注自己的 QQ），
   然后给机器人发「我赞助了 / 我购买了」，插件调用爱发电开放接口校验订单，
   校验通过自动放行，并私聊通知管理员。

## 配置

在 AstrBot WebUI 的插件配置里填写：

| 配置 | 说明 |
| --- | --- |
| `whitelist` | 准入白名单 QQ，始终放行不计数 |
| `max_rounds` | 免费对话轮数，默认 6 |
| `round_window` | 轮次合并窗口秒数，默认 180 |
| `afdian_url` | 你的爱发电主页，如 `https://afdian.com/a/xxx` |
| `afdian_user_id` / `afdian_token` | 爱发电后台「开发者设置」页获取（https://afdian.com/dashboard/dev） |
| `min_amount` | 有效赞助最低金额（默认 5 元，按实付计） |
| `notify_target` | 管理员 QQ，赞助自动通过时会私聊通知 |

赞助未配置完整时，机器人只提示「等待同意」，不会给出无法兑现的赞助入口。

## 管理命令

```
/准入 同意 <QQ号> [天数]   # 手动放行（可限时，如 同意 123456 30），并私聊通知对方
/准入 移除 <QQ号>          # 移出白名单
/准入 拉黑 <QQ号>          # 黑名单：之后的消息一律静默忽略
/准入 解黑 <QQ号>          # 移出黑名单
/准入 订单 <订单号> <QQ号> # 手动核销订单并绑定（对方忘写/写错QQ时的兜底）
/准入 状态 <QQ号>          # 查询某人聊到第几轮、是否被拦截
/准入 重置 <QQ号>          # 清零某人的轮次（再给一轮机会）
/准入 统计                 # 触发/赞助/手动放行 次数
/准入 列表                 # 白名单 + 限时放行 + 黑名单 总览
```

（仅 AstrBot 管理员可用；AstrBot 管理员聊天本身自动豁免，不会被计数）

## 校验规则

- 订单状态必须为「交易成功」（status=2），未支付订单不能核销；
- 实付金额 ≥ `min_amount`；
- 订单留言中必须包含对方的 QQ 号（独立数字匹配）；
- 同一人两次校验间隔不小于 `check_cooldown` 秒，防止刷接口；
- 订单核销台账：每个订单号只能绑定一个人一次，防重复使用。

## 订单防呆设计

- **留言忘写 QQ**：插件查到金额达标但留言没有号码的订单时，会把订单号告诉对方，
  并私聊通知管理员；确认后用 `/准入 订单 <订单号> <QQ号>` 一键绑定放行；
- **留言写错 QQ**（写了别的号码）：单独提示对方核对，避免误绑；
- **手动核销**：按订单号精确查询爱发电接口核验后绑定，低于门槛金额的订单会提示
  改用 `/准入 同意`。

## 商品（售卖方案）支持

爱发电「按份购买数字内容/实体商品/捆绑包」的订单同样有效：
`product_type=1` 的售卖订单与普通赞助一视同仁，按 `sku_detail` 中的购买份数折算
有效期——例如 `sponsor_expire_days=30` 时买 2 份得 60 天（设为 0 则永久）。

## 其他说明

- 轮次/凭证/统计持久化在 `data/plugin_data/astrbot_plugin_sponsor_pass/state.json`，AstrBot 重启不清零；
- `sponsor_expire_days` > 0 时，赞助放行带有效期，到期自动出列并提示对方续期；
- 陌生人触发门槛时会私聊通知管理员（每人每天最多一次，`notify_on_gate` 可关）；
- 好友申请/通知事件独立放行，不影响人际关系等插件的审批流；
- 本插件只处理**私聊**，不影响群聊；
- 若同时使用 whitelistpro，请关闭其「好友私聊白名单」，避免双重拦截。
